## _buffers
Next / prev buffer               | <Tab> / <S-Tab>
New buffer                       | :enew
Close current buffer             | <leader>x
Close all buffers but current    | <leader>X
Path of current file             | <C-g>

## _tabs
New tab                          | :tabnew
Next tab                         | <leader><leader>
Next / prev tab                  | gt / gT
Help moving windows              | :help :wincmd

## _finding
Find files                       | <leader>ff
Live grep (with rg args)         | <leader>fw
Quote the grep prompt            | <C-k>
Append an --iglob filter         | <C-i>
File browser                     | <leader>fb
Find files in another dir (once) | :Telescope find_files cwd=path
Grep in another dir (once)       | :Telescope live_grep cwd=path
Search several dirs at once      | :Telescope find_files search_dirs={"a","b"}

## _working-directory

Change dir (rest of session)     | :cd path
Change dir (this tab only)       | :tcd path
Change dir (this window only)    | :lcd path
Back to previous directory       | :cd -
